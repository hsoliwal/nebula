Model interpolation has no MavenSession object source. session.topLevelProject.basedir is evaluated in plugin parameter expressions and can denote the selected nested project; it is not an admitted repository-model root expression. Maven 3.9.14 does additionally support session.rootDirectory and session.topDirectory in CLI property/argument interpolation, including -D values from maven.config. Those return Path.toString and provide no URI encoding or toUri selector. [MavenCli, createInterpolator/populateProperties](https://maven.apache.org/ref/3.9.14/maven-embedder/xref/org/apache/maven/cli/MavenCli.html), [plugin parameter evaluator](https://raw.githubusercontent.com/apache/maven/maven-3.9.14/maven-core/src/main/java/org/apache/maven/plugin/PluginParameterExpressionEvaluator.java)

Pinned Tycho 4.0.12 uses only system_property:, env_var:, and project_loc: target-variable forms. The system_property form reads a merged session property map: system properties, active settings profiles, then user properties; POM project properties are excluded. project_loc searches reactor projects and returns File.getAbsolutePath, so it also has Windows separators and fails to locate a parent that is not in a standalone child reactor. Bare Maven expressions in the target are not expanded. [variable resolver](https://raw.githubusercontent.com/eclipse-tycho/tycho/ff2f4fabcea3c5f18cae5a32146bf5defab95d6e/tycho-core/src/main/java/org/eclipse/tycho/p2resolver/DefaultTargetDefinitionVariableResolver.java), [global session properties](https://raw.githubusercontent.com/eclipse-tycho/tycho/ff2f4fabcea3c5f18cae5a32146bf5defab95d6e/tycho-core/src/main/java/org/eclipse/tycho/osgi/configuration/MavenContextConfigurator.java)

For an InstallableUnit location, Tycho passes the expanded repository string directly to new URI. It does not resolve the repository against the target file origin, and does not call convertRawToUri. That conversion applies to other location kinds and only changes slashes/prefixes; it is not space encoding. The unchanged URI reaches the p2 repository manager, whose contract requires absolute URIs. Thus neither a relative target repository nor file:///${system_property:maven.multiModuleProjectDirectory}/... is an admitted universal replacement. [target resolver](https://raw.githubusercontent.com/eclipse-tycho/tycho/ff2f4fabcea3c5f18cae5a32146bf5defab95d6e/tycho-core/src/main/java/org/eclipse/tycho/p2resolver/TargetDefinitionResolver.java), [p2 URI loading](https://raw.githubusercontent.com/eclipse-tycho/tycho/ff2f4fabcea3c5f18cae5a32146bf5defab95d6e/tycho-core/src/main/java/org/eclipse/tycho/p2/resolver/URITargetDefinitionContent.java), [p2 absolute URI contract](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.isv/reference/api/org/eclipse/equinox/p2/repository/IRepositoryManager.html)

Maven's model URL normalizer removes /../ segments; it does not replace Windows slashes or percent-encode path characters. Tycho's MavenContext also converts repository URL through URL.toURI, which can reject such raw values. Effective-POM text alone therefore cannot prove Tycho repository acceptance. [exact URL normalizer](https://raw.githubusercontent.com/apache/maven/maven-3.9.14/maven-model-builder/src/main/java/org/apache/maven/model/path/DefaultUrlNormalizer.java), [Tycho repository conversion](https://raw.githubusercontent.com/eclipse-tycho/tycho/ff2f4fabcea3c5f18cae5a32146bf5defab95d6e/tycho-core/src/main/java/org/eclipse/tycho/osgi/configuration/DefaultMavenContext.java)

Reuse one URI-valued property for the three parent URL values, defined in the real inheritable releng parent or supplied as an early session/user property.
