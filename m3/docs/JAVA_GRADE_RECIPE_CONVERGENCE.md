# Nebula M3 Java-grade convergence and backport gate

A Nebula change is Java-grade only after the existing Java 21 Maven/OpenRewrite recipe DAG,
product build and transfer/backport evidence are bound into one content-addressed qualification.

The mutation unit remains a small OpenRewrite recipe atom. FILE convergence remains:

```text
INVENTORY -> ATOMIZATION -> PATTERNIZATION/IOP -> DOCUMENTATION -> FILE FIXED POINT
```

Authority grows only when a semantic boundary actually grows:

```text
FILE -> VISIBILITY -> PACKAGE -> MODULE -> MULTI_MODULE -> LIBRARY_API
```

Maven/OpenRewrite remains the execution/proof root. Camel, Airflow and Drools/KIE are projections of
the same DAG and have no mutation or promotion authority.

The Java-grade receipt binds:

- Java 21 and the pinned OpenRewrite version;
- recipe DAG root;
- Camel/Airflow/Drools projection root;
- 99% semantic line-coverage threshold;
- complete proof-stage receipt;
- transfer-contract root;
- backport-plan root;
- canonical scope order;
- target repositories.

The backport plan is executable programme state, not future documentation:

```text
Nebula portable/product proof
 -> Synexia recipe absorption
 -> Synexia recipe proof
 -> M3JDK21 Maven/OpenRewrite bootstrap around the existing OpenJDK build
 -> JEP/PR/tooling/dependency inventory
 -> contract-preserving FILE recipe replay
 -> VISIBILITY/PACKAGE/MODULE/MULTI_MODULE/LIBRARY_API promotion only when required
 -> target diff/lint/compile/jtreg/JUnit/runtime/JNI/benchmark/fixed-point proof
```

Any missing proof stage keeps the qualification at `HOLD`.
A complete receipt becomes `MANUAL_TRANSFER_REVIEW_REQUIRED`; it still cannot edit target source,
merge a branch, or promote a release by itself.
