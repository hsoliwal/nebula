# Default named composite effects

M3DonorMavenizedAtomPatternRecipe composes the existing structural Java observer and algorithm atom recipe-crate observer. The latter is constructed with an empty manifestOutputPath, so its generate method returns no new source. A nonempty path configured directly on that leaf may generate a TSV; this default composite does not use it. Neither child adds a POM, a dependency, a plugin, or Mavenizes an unbuilt repository. Mavenized describes the expected input.

M3HierarchicalAtomPatternRecipe composes five-scope planning, Markdown/AsciiDoc atom inventory, Java source visibility/declaration inventory, framework pattern tables, and mechanical donor catalog tables. Plan/document/framework generation returns no source; the visibility and mechanical observers return the supplied tree. Default execution includes no file cleanup, static-analysis1.4.2, replacement visitor, or POM mutation. Unsupported/unparsed/unresolved sources remain explicit residue. Cancellation/scheduler diagnostics are separate from a successful source-preserving run.

The exact source hashes for every child are bound in SOURCE_RESOURCE_TEST_MANIFEST.json. Actual exported table/path/raw-hash joins are required before recording coverage; catalog rows are not native algorithm or behavior proof.
